SDLReader reads PDFs, CBZ / ZIP and CBR / RAR comic archives, EPUB and MOBI
ebooks, plain text, and image files.

## Install

Install **SDLReader** from Pak Rat; see
[installing an app](/app-store/introduction/#installing-an-app). It appears in
your **Apps** tab.

## Adding documents

Put your files anywhere on the SD card and browse to them in the app. The file
browser remembers the last directory you were in.

Press **X** in the browser to switch between a plain list and a thumbnail grid
that previews covers.

## Reading

Zoom in and out, fit a page to the screen width, scroll within an oversized
page, and rotate or mirror the view to suit how you're holding the device.
Reading history keeps your place in each document.

The font and reading-style menu (the **MENU** button, or **L1 + R1**) holds the
rest:

- Reading themes for EPUB, MOBI, and text: Sepia, Dark Mode, High Contrast,
  Paper Texture, Soft Gray, and Night Mode.
- A font picker.
- Page jump, with an on-screen number pad.
- A document minimap and an edge progress bar.
- Edge-turn behavior.

## Controls

In the file browser:

| Button | Action |
|---|---|
| **D-pad** | navigate; page through long lists |
| **L1** / **R1** | jump by letter |
| **A** | open |
| **B** | go back |
| **X** | switch between list and thumbnail grid |
| **MENU** | quit |

While reading a document:

| Button | Action |
|---|---|
| **D-pad** | scroll / pan; hold at a page edge to turn the page |
| **L1** / **R1** | previous / next page |
| **L1 + R1** | open the font & reading-style menu |
| **L2** / **R2** | jump back / forward 10 pages |
| **L2 + R2** | reset the page view |
| **X** | zoom in |
| **A** | zoom out |
| **B** | fit page to width |
| **Y** | rotate 90° clockwise |
| **START** | toggle horizontal mirror |
| **SELECT** | toggle vertical mirror |
| **MENU** | open the font & reading-style menu |
